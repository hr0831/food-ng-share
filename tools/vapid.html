通知用のカギを作る

プッシュ通知に必要な鍵を作ります。鍵はこのページの中（あなたの端末）だけで作られ、 どこにも送信されません。

押すたびに新しい鍵ができます。設定し終わるまでこのページを閉じないでください。

① 公開カギ（VAPID public key）

アプリの config.js に書きます。公開されて構いません。

② 秘密のカギ（VAPID private key）

Supabase の Edge Functions のシークレットにだけ貼ります。
config.js や GitHub には絶対に書かないでください。他人に通知を送られてしまいます。

③ 合言葉（Webhook secret）

通知の呼び出しが本物かを確かめるための合言葉です。
Supabase のシークレットと Webhook の設定の両方に貼ります。これも公開しないでください。

この3つをどこに入れるか

  1. ① → アプリの config.js
  2. ② → Supabase の Edge Functions シークレット VAPID_PRIVATE_KEY
  3. ③ → Supabase の Edge Functions シークレット WEBHOOK_SECRET と、Database Webhook のヘッダー

①には、あわせて連絡先メールも必要です（通知サーバからの連絡用）。詳しい手順は README を見てください。
